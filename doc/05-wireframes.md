# 03 - Wireframes

# Suqly MVP Wireframes

This document outlines the screens required for the Suqly MVP and the main components displayed on each screen.

---

# Public Pages

## 1. Landing Page

Purpose:
Introduce Suqly and allow users to authenticate.

Components:

- Navigation Bar
- Hero Section
- Features Section
- Call to Action
- Sign In Button
- Register Button
- Footer

Actions:

- Sign In
- Register

---

## 2. Login

Components:

- Email
- Password
- Sign In Button
- Forgot Password (Optional)
- Register Link

Actions:

- Login

---

## 3. Register

Components:

- Full Name
- Phone Number
- Email
- Password
- Confirm Password
- Select Role:
  - Business Owner
  - Customer
- Register Button

Actions:

- Create Account
